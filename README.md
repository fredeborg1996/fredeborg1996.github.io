# Din Virksomhed

En enkel, responsiv virksomhedshjemmeside bygget som statisk HTML og CSS.

## Kør lokalt

Start en lokal webserver fra projektmappen:

```bash
python3 -m http.server 8000
```

Åbn derefter siden i browseren på:

```text
http://localhost:8000/Index.html
```

## Tilpasning

Udskift pladsholderne `Din Virksomhed`, `kontakt@dinvirksomhed.dk`, CVR, telefon og adresse med virksomhedens rigtige oplysninger.
